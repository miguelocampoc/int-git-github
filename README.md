# Calculadora de Interés Simple (Simple Interest Calculator)

Este repositorio contiene un proyecto práctico desarrollado como parte del curso **Introducción a Git y GitHub** de IBM. Su propósito es demostrar el flujo de trabajo básico de control de versiones utilizando Git y la interfaz de GitHub.

## Descripción del Proyecto
El script principal calcula el interés simple basándose en el capital inicial, la tasa de interés anual y el período de tiempo especificado por el usuario.

Fórmula utilizada:
$$A = P (1 + rt)$$

Donde:
* **A** = Capital Final (Valor total de la inversión/préstamo)
* **P** = Capital Inicial (Monto principal)
* **r** = Tasa de interés anual (en decimales)
* **t** = Período de tiempo (en años)

## Características
* Script en Bash (`simple-interest.sh`) interactivo para el cálculo rápido de intereses.
* Documentación de soporte que incluye Licencia Apache 2.0, Código de Conducta y Guías de Contribución.
